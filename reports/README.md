# Informes Técnicos y Benchmarks 📈

Documentación cuantitativa y cualitativa del proceso de experimentación y evaluación de modelos:

## Contenido
- **`informe_clasificacion.md`**: Informe técnico detallado sobre el problema, preparación de datos con matriz negra, formulación matemática de los modelos y análisis de errores.
- **`metricas_resumen.csv`**: Tabla de resultados comparativos en el conjunto de prueba (Test Set 20%):
  - Accuracy
  - Precision
  - Recall
  - F1-Score
