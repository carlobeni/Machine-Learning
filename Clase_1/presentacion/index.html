Introducción a Machine Learning

Tradicionalmente, en la programación, le pedimos a un experto humano que escriba reglas lógicas (una función $f$) para resolver un problema.

En Machine Learning, invertimos el paradigma: tratamos al modelo como una "caja negra" (Black Box). Introducimos datos ($\mathcal{D}$), y un algoritmo aprende a configurar los parámetros de esa caja para producir la salida correcta.

Ejemplo clásico (Andrew Ng): Predicción de precios de vivienda en Portland. Si alimentamos nuestra "caja" con el área de las casas y el número de dormitorios como *features*, la caja aprenderá a predecir o estimar el precio de venta (*target*) de una casa nueva que nunca ha visto.

Categorías de Machine Learning

Según el tipo de aprendizaje:

  • Supervised Learning: El modelo aprende con datos etiquetados (entradas con salidas conocidas).
  • Unsupervised Learning: Los datos no tienen etiquetas. Busca estimar la estructura natural.

Según la naturaleza del problema:

  • Clasificación: Salidas con valor discreto (categorías).
  • Regresión: Salidas con valor continuo.

Algunos Modelos Centrales de Machine Learning 1

I. Regresión & GAM

Modelando relaciones entre variables.

Regresión Lineal: Ajusta una función lineal a los datos. Es muy interpretable (ej. CAPM).

Ridge y Lasso: Mejoran la predicción manejando alta correlación mediante regularización.

Observación: GAM (Generalized Additive Models)

Suma de funciones no lineales que predice relaciones complejas sin perder interpretabilidad:

$g(E(Y)) = \beta_0 + f_1(X_1) + f_2(X_2) + \dots + f_p(X_p)$

II. Árboles de Decisión

Ensamblajes: Bagging y Boosting con Figuras Visuales

Árbol de Decisión: Segmenta características. Es visual pero inestable por sí solo.

Random Forest (Bagging): Ensambla múltiples árboles descorrelacionados para mayor precisión.

XGBoost (Boosting): Árboles secuenciales que aprenden de errores anteriores. Muy robusto.

III. Clustering (Agrupamiento)

Encontrando grupos naturales.

El Clustering agrupa datos sin etiquetar basándose en sus similitudes.

K-Means: El algoritmo más común. Asigna cada punto al centroide ($k$) más cercano minimizando las distancias.

Formalismo Matemático (Inercia):

$\arg\min_{S} \sum_{i=1}^{k} \sum_{\mathbf{x} \in S_i} || \mathbf{x} - \boldsymbol{\mu}_i ||^2$

IV. Reducción de Dimensionalidad (PCA y SVD)

Simplificando la complejidad matemática.

PCA: Combina variables en componentes principales independientes. Reduce la redundancia conservando la varianza.

SVD (Singular Value Decomposition)

La factorización matricial fundamental de la que deriva PCA:

$X = U \Sigma V^T$

Donde $U$ son los vectores singulares izquierdos, $\Sigma$ la matriz diagonal de valores singulares, y $V^T$ los vectores singulares derechos ortogonales.

V y VI. Deep Learning & NLP

Formas más avanzadas de Inteligencia Artificial.

Deep Learning (DL)

Redes neuronales artificiales (ANN) con múltiples capas complejas para procesar información imitando el cerebro. Procesan datos en secuencias y mejoran enormemente la precisión de predicción, aunque son una "caja negra".

Natural Language Processing (NLP)

Analiza grandes cantidades de texto para extraer insights. En el sector financiero se usa para detectar el tono en reportes o impacto de noticias.

Ecosistema del Machine Learning

¿Por qué usamos Python?

Python se ha consolidado como el lenguaje estándar absoluto en la industria e investigación de Inteligencia Artificial.

  • Sintaxis legible y minimalista: Permite centrarse en la matemática y la lógica, no en los pormenores del lenguaje.
  • Ecosistema insuperable: Acceso a bibliotecas robustas para cálculo científico y procesamiento de datos.
  • Comunidad y soporte global.
