# Plantilla del Proyecto de Machine Learning

Esta rama contiene la estructura base para el desarrollo del proyecto final.

## Estructura
- notebooks/: Jupyter notebooks para EDA y modelado
- data/: Conjuntos de datos (raw/ y processed/)
- models/: Modelos entrenados
- api/: API para servir el modelo
- dashboard/: Aplicación interactiva
- docs/: Documentación y GitHub Pages
- reports/: Informes y reportes
- presentation/: Presentaciones
